# THE-text-editor
The only text editor you'll ever need!!!
Written in C for pure performance!!!




## Setup and Installation

> [!NOTE]
> You'll need to install git, gcc and make.

Clone the repo and cd into it. 

```bash
    git clone https://github.com/wnck777/THE-text-editor
    cd THE-Text-editor
```

To run the editor it's important to compile the program with make.
```bash
    make
```
and run with

    ./text-editor
